# PriorityMatch – Priority-Based Compatibility Matching Algorithm

PriorityMatch is a DSA-based matching algorithm using priority queues and greedy logic
to balance user visibility and compatibility.

## Key Features
- Priority Queue (Heap)
- Greedy Matching Strategy
- Custom Data Structures
- Real-world algorithmic thinking

## Run
```
g++ src/main.cpp -o prioritymatch
./prioritymatch
```
